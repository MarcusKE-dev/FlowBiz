# Where the demo photographs came from

Every food photograph in this folder is from **Wikimedia Commons**, chosen
because it needs no API key and because each file carries machine readable
licence metadata, so this list can be checked rather than trusted.

These images ship in the public demo build. Files marked **CC BY** or
**CC BY-SA** require attribution when redistributed, which is what this
file is for. Public domain and CC0 files need none and are listed anyway.

To replace any of them: drop a new `<slug>.webp` in this folder (512x512,
under 45KB, see README.md) and update the row here.

## A note on the drinks

`coca-cola.webp` and `fanta.webp` are **generic** photographs of a cola and
an orange soda, not the branded products the demo rows are named after.
That is deliberate: the demo needs a picture that reads as the drink from
across a room, and it should not put a trademark on a screen it does not
own.
